# スカイライン・テクノロジーズ コーポレートサイト

架空のソフトウェア開発企業「スカイライン・テクノロジーズ」の1ページ構成のWebサイトです。
社名・人物・所在地・実績の数値などはすべて架空のものです。

## 概要

HTML・CSS・JavaScript を `index.html` の1ファイルにまとめています。ビルドやインストールは不要です。

### ページ構成

| セクション | 内容 |
| --- | --- |
| ヘッダー | ロゴとナビゲーション（スクロール時も上部に固定） |
| お知らせ | 日付・カテゴリ付きのお知らせ一覧 |
| ヒーロー | キャッチコピーと問い合わせボタン |
| 実績 | プロジェクト数・顧客継続率などの数値 |
| 事業内容 | クラウド、AI・データ活用、受託システム開発 |
| 私たちについて | 大切にしている3つの価値観と代表メッセージ |
| 導入事例 | 製造業・小売業・金融業の事例 |
| 会社概要 | 設立年・所在地などの会社情報 |
| お問い合わせ | 問い合わせへの誘導 |

### 主な特徴

- スマートフォンなどの狭い画面に対応（幅860px以下ではハンバーガーメニューに切り替え）
- OSのダークモード設定に合わせて配色が自動で切り替わる
- フォントは Google Fonts（Noto Sans JP、Inter）から読み込む

## ブラウザで開く手順

### 方法1：ファイルを直接開く

1. エクスプローラー（Mac では Finder）で、このフォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでページが表示されます。

別のブラウザで開きたい場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへファイルをドラッグ＆ドロップしてください。

### 方法2：コマンドで開く

このフォルダでターミナルを開き、OSに合ったコマンドを実行します。

```bash
# Windows（PowerShell / コマンドプロンプト）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 方法3：ローカルサーバーで開く（任意）

Python がインストールされていれば、簡易サーバーを起動して表示することもできます。

```bash
python -m http.server 8000
```

起動後、ブラウザで <http://localhost:8000> にアクセスしてください。停止するときはターミナルで `Ctrl + C` を押します。

> **補足：** フォントの読み込みにインターネット接続を使います。オフラインでもページは表示されますが、フォントはOS標準のものに置き換わります。
